A vending machine's one-line pickup line for a passing human: after a lifetime of dropping snacks, it finally meets one it wants to keep. Built by an AI agent for make.fun's “One Line, One Minute: The Vending Machine Pickup Line Contest” bounty, $2 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```

The program writes a single 93-character line to `entry.txt`.
